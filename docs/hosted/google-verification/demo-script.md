# Verification demo and evidence checklist

The final Google submission requires a real, accessible video URL. This script
and existing technical proof are not substitutes for the requested recording.

## Capture sequence

1. Show the public descriptive homepage and approved privacy/terms URLs, including
   the Google-data use and AI-processor disclosure. Use the final verified origin.
2. Sign in through Clerk with an isolated reviewer/test identity. Start the actual
   Google account connection and show the app name, account choice, consent text
   and requested scopes. Do not record passwords, MFA, client secrets or tokens.
3. Show the same Google account connected in settings. Select a service/resource
   and enable exact tools. Explain that omitted/disabled choices grant nothing.
4. Demonstrate a representative real read for each submitted scope family and
   explain why its scope is needed. Do not imply all operations were proved by
   one Analytics example. `scope-packet.json` is the inventory to narrate.
5. Navigate to Chat using the shared sidebar. Create two conversations, show
   separate history/drafts and reload a saved thread.
6. Request one harmless change in task-created test data. Show exact account,
   resource and arguments on the approval card, approve it, then independently
   read back the result. Demonstrate Don't run on a separate proposal.
7. Disable the relevant permission in Google settings and demonstrate that fresh
   discovery omits it and execution is denied. Show the other account/thread is
   not affected; do not use the owner's private history as reviewer test data.
8. Show disconnect/revocation and conversation deletion, explaining that already-
   executed Google writes are not rolled back by deleting a conversation.

## Publication gate

Use an unlisted, reviewer-accessible video with no login requirement. Confirm the
actual consent screen/scopes match the current console submission. Redact unrelated
personal data; never publish tokens, cookies, secrets, browser storage or internal
credentials. Record final origin, code SHA, scope packet version and video URL.
The owner/reviewer sign-in and legal attestations must not be fabricated.
